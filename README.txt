Prescott house hunt (ERAU Prescott, move-in ~Dec 1 2026)
=========================================================

Static site, no build step, no API keys. Live copy: https://krystianwalec.github.io/prescott-rentals/

Open locally: double-click index.html (data is embedded in listings-data.js / updates-data.js, so it works
from file://), or run `python3 -m http.server 8000` in this folder and open http://localhost:8000/.

Files
-----
index.html, styles.css, app.js     page, style, logic (Leaflet + OpenStreetMap map, cards, filters, daily-updates blog)
listings.json / listings-data.js    current + gone listings, sources status, excluded list (same data twice)
updates.json / updates-data.js      one post per daily refresh (new / price changes / gone / market note)
.nojekyll                           GitHub Pages serves files as-is

Do not hand-edit the data files: they are regenerated by /workspace/prescott-rentals-refresh/refresh.py
(see the README there).
